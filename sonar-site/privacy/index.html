PRIVACY / 隐私说明

数据留在你的网络里

Sonar 是一个点对点的局域网文件传输工具。没有账号体系，没有中转服务器，也没有埋点统计。这份说明写清楚它在你的设备上放了什么、又永远不会发出什么。

01 / COLLECT

我们收集什么

没有。 项目里没有账号系统、统计平台或崩溃上报服务，也没有任何把设备信息、文件元数据或使用记录发往开发者服务器的通道。

你看到的设备列表来自同一局域网内的广播通告；传输请求直接发往那台设备的 IP。我们既不知道你传了什么，也不知道你传给了谁。

02 / ON DEVICE

设备上保存什么

应用把偏好和状态保存在设备本地（SharedPreferences / 应用私有存储），主要包括：

  • 设置：设备别名、端口、接收策略、快速保存、主题与语言。
  • 收藏设备：别名与设备证书指纹，用于下次识别。
  • 传输历史：对端别名、文件名、类型、大小、本地路径与时间。
  • 最近设备：用于更快找到上次传过的设备。

调试页里的发现日志与 HTTP 日志只存在于本次运行的内存中，各最多保留 200 条，重启即清空，不写入文件也不上传。

这些内容不会自动上传。清除应用数据或卸载应用即可全部删除；你也可以单独清空传输历史与收藏。

03 / TRANSFER

传输过程

发现阶段使用 UDP 组播，只在同一网络内通告“这里有设备”。注册与文件传输走直连的 HTTP/HTTPS：HTTPS 使用按设备生成的证书，并要求对端提供客户端证书，证书指纹用来确认身份；你还可以设置 PIN 作为额外确认。

Web 分享页面由你自己的设备本机提供，PIN 在服务启动时固定。浏览器面对的是你的设备，不是我们的服务器。当前版本中的 WebRTC / 公共信令通道在源码里标注为关闭；若将来启用，会先更新本页。

04 / PERMISSIONS

权限怎么用

Android：本地网络权限用于发现和连接附近设备；文件与照片权限用于选择要发送的文件、保存收到的文件；通知权限用于传输进度。安装未知应用仅在你主动安装收到的 APK 时使用；查询应用列表用于挑选要分享的已安装应用。

iOS：本地网络权限用于发现附近设备，照片库权限用于选择和保存媒体。系统文案里出现的“位置”描述，实际用途是读取本机局域网 IP，不用于定位，也不做后台位置追踪。

拒绝某项权限后，只有对应的功能不可用，不影响其他功能。

05 / EXTERNAL

外部链接

官网里的 GitHub、Gitee Release、上游 LocalSend 与捐赠入口都是外部站点。点击链接后，你在那些站点上的行为适用它们各自的隐私政策，而不是本页。

F-Droid 等 FOSS 构建会在打包时移除捐赠模块，不会包含相关入口。

06 / CONTROL

你的控制与反馈

你可以随时关闭快速保存与 Web 分享、移除收藏设备、清空传输历史；卸载应用会删除全部本地数据。清除应用数据或重装后设备身份会重新生成，旧的收藏记录自然失效。

对隐私有疑问，可在 GitHub 仓库 提 issue；安全问题请使用仓库的 Security Advisory 私下反馈，不要公开披露。
